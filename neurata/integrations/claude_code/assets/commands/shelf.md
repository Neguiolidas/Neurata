---
description: Inspect the Neurata shelf: full inventory, usage insights, or conflicts.
argument-hint: [inventory|insights|conflicts]
---

Use the `neurata_shelf` MCP tool with the view: $ARGUMENTS (default
`inventory`).

Summarize the result briefly: for `inventory`, the highest-scored grains and
the archival candidates; for `insights`, the top used and never-used grains;
for `conflicts`, any conflicts or collisions that need a decision.
